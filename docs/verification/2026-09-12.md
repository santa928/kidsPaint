# タブレット向け改修の検証記録

2026-09-12。基準コミット `8f3d5470db243916678cf297c605861cb00447b3` から、`codex/tablet-paint-refresh` のローカル変更を確認した。本番公開・mainへのマージは実施していない。

## 実装した内容

既存React・TypeScript・Canvas 2Dを維持し、クレヨンと紙を中心にUIを刷新した。描画は作品座標の操作列、画面は固定比率で表示し、DPRは最大2。単一接点の所有、回転・配置移動・cancel時の入力確定、鉛筆と消しゴムの排他状態、20回Undo、復元可能な全消去を実装した。

作品と背景はIndexedDBへ保存し、作品帳から再開・個別PNG保存できる。新しい紙へ移る前に現在の絵を保存し、失敗した場合は現在の絵を保持する。保存時に更新時刻を比較して他タブの新しい絵を上書きしない。初期読込失敗を空の作品帳として扱わない。

500ストローク・60,000点・20%虹色の合成作品を読み込み、120回のネイティブpointer移動、その後40回の連続タップを実行した。実機iPadの測定ではない。

## 失敗の切り分けと残る確認

- Linux WebKitの `context.setOffline(true)` は、キャッシュとcontrollerが存在してもfetch/reloadで `WebKit encountered an internal error` になった。この方法を成功証拠には使っていない。HTTPキャッシュを `no-store` にした使い捨て本番サーバを実停止し、到達不能を確認する方式でChromium/WebKitともに完走した。
- HTTPの検証ホストでは `crypto.randomUUID` が使えず初期化に失敗した。`crypto.getRandomValues` の代替へ修正。専用e2eはPWA検証のためlocalhostのネットワークを共有する。
- iPad実機、実際の3歳児の理解・誤操作、Apple Pencil/手のひら、音量・音質・音の遅延、Safariから写真/ファイルへ残す操作、ホーム画面PWAの更新・長時間利用は未確認。
- `beforeunload` は保存未完了時の補助。iOSによる強制終了やブラウザ保存領域の削除を防ぐ保証はない。
- 本番URLの確認、Lighthouse、全端末比較、長時間soak、公開は今回行っていない。公開前に代表iPadで操作・音・保存・PWAを確認し、リリース内容に応じてこれらの検査を実施する。
